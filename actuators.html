Servo Motor SG90

Rotates 0°–180° with precision. PWM controlled. 3 wires: Red=VCC, Brown=GND, Orange=Signal.

Specifications

Voltage4.8V – 6V
Torque1.8 kg/cm
Rotation0° – 180°
ControlPWM 50Hz

Wiring

Red→5V | Brown→GND | Orange→D9

Arduino Code

Arduino C++
// Servo Motor – LearnEmbedded
#include <Servo.h>
Servo myServo;
void setup(){ myServo.attach(9); }
void loop(){
  for(int i=0; i<=180; i+=5){ myServo.write(i); delay(50); }
  for(int i=180; i>=0; i-=5){ myServo.write(i); delay(50); }
}

DC Motor + L298N Driver

Continuous rotation motor. Needs L298N H-bridge driver for direction and speed control via PWM.

Specifications

Motor Voltage6V – 12V
DriverL298N H-Bridge
Max Current2A per channel
Speed ControlPWM (0–255)

Wiring

IN1→D5 | IN2→D6 | ENA→D3(PWM) | OUT1/OUT2→Motor

Arduino Code

Arduino C++
// DC Motor L298N – LearnEmbedded
const int in1=5, in2=6, ena=3;
void setup(){ pinMode(in1,OUTPUT); pinMode(in2,OUTPUT); }
void loop(){
  digitalWrite(in1,HIGH); digitalWrite(in2,LOW);  analogWrite(ena,200); delay(2000); // Forward
  digitalWrite(in1,LOW);  digitalWrite(in2,HIGH); analogWrite(ena,200); delay(2000); // Reverse
  digitalWrite(in1,LOW);  digitalWrite(in2,LOW);  delay(1000); // Stop
}

Stepper Motor 28BYJ-48

Rotates in precise steps (512 steps = 1 full revolution). Uses ULN2003 driver module.

Specifications

Voltage5V DC
Steps/Rev512 steps
Gear Ratio64:1
DriverULN2003

Wiring

IN1→D8 | IN2→D9 | IN3→D10 | IN4→D11

Arduino Code

Arduino C++
// Stepper Motor – LearnEmbedded
#include <Stepper.h>
Stepper stepper(512, 8, 10, 9, 11);
void setup(){ stepper.setSpeed(15); }
void loop(){
  stepper.step(512);  delay(500);  // Forward 1 rev
  stepper.step(-512); delay(500);  // Reverse
}

Relay Module

Electrically controlled switch. Controls high voltage AC/DC appliances with 5V Arduino signal.

Specifications

Coil Voltage5V DC
AC Rating250VAC / 10A
DC Rating30VDC / 10A
TypeActive LOW (usually)

Wiring

VCC→5V | GND→GND | IN→D7 | (LOW=ON)

Arduino Code

Arduino C++
// Relay Module – LearnEmbedded
const int relay = 7;
void setup(){ pinMode(relay,OUTPUT); digitalWrite(relay,HIGH); } // HIGH=OFF
void loop(){
  digitalWrite(relay,LOW);  delay(3000); // Device ON
  digitalWrite(relay,HIGH); delay(3000); // Device OFF
}

Buzzer (Active)

Produces sound when HIGH. Active buzzer beeps at fixed frequency. Use tone() for passive buzzer.

Specifications

Voltage5V DC
Current~30 mA
Frequency2300 Hz (active)
TypeActive / Passive

Wiring

(+)→D8 | (-)→GND

Arduino Code

Arduino C++
// Buzzer SOS – LearnEmbedded
const int buzz = 8;
void setup(){ pinMode(buzz,OUTPUT); }
void loop(){
  for(int i=0;i<3;i++){ digitalWrite(buzz,HIGH);delay(100);digitalWrite(buzz,LOW);delay(100); }
  delay(1000);
}

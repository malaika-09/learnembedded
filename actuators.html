Servo Motor SG90

Rotates 0°–180° with precision. PWM controlled. 3 wires: Red=VCC, Brown=GND, Orange=Signal.

Specifications

Voltage4.8V – 6V
Torque1.8 kg/cm
Rotation0° – 180°
ControlPWM 50Hz

Pin Diagram

   SG90 Servo (3-wire connector)
  ┌────────────────────┐
  │    [Motor Body]    │
  │    ┌──────────┐    │
  │    │  [Gear]  │    │  ← Nylon gear system
  │    └──────────┘    │
  └────────┬───────────┘
           │
     ┌─────┴──────┐
     │  3-pin JST │
     └──┬──┬──┬───┘
        Br Rd Or
        G  V  S
        N  C  I
        D  C  G
  ■ Brown  = GND  → GND
  ■ Red    = VCC  → 5V (external recommended)
  ■ Orange = SIG  → D9 (PWM ~)

Full Datasheet

Operating Voltage4.8V – 6V DC
Stall Torque1.8 kg/cm @ 5V
No-load Speed0.1 sec / 60°
Rotation Range0° – 180°
PWM Frequency50 Hz
Pulse Width 0°500 µs
Pulse Width 90°1450 µs
Pulse Width 180°2400 µs
Weight9 g
Gear MaterialNylon

Pin Connection Table

Wire ColorPin NameFunctionConnect To
BrownGNDGroundGND
RedVCC5V Power5V (external preferred)
OrangeSIGPWM SignalD9 (~) PWM pin
⚠️Do NOT power multiple servos from Arduino 5V pin — it draws too much current. Use an external 5V supply. Always connect GND of external supply to Arduino GND.

Wiring

Red→5V | Brown→GND | Orange→D9

Arduino Code

Arduino C++
// Servo Motor – LearnEmbedded
#include <Servo.h>
Servo myServo;
void setup(){ myServo.attach(9); }
void loop(){
  for(int i=0; i<=180; i+=5){ myServo.write(i); delay(50); }
  for(int i=180; i>=0; i-=5){ myServo.write(i); delay(50); }
}

DC Motor + L298N Driver

Continuous rotation motor. Needs L298N H-bridge driver for direction and speed control via PWM.

Specifications

Motor Voltage6V – 12V
DriverL298N H-Bridge
Max Current2A per channel
Speed ControlPWM (0–255)

Pin Diagram (L298N Module)

     L298N Driver Module (top view)
  ┌──────────────────────────┐
  │  [12V] [5V] [GND]      │  ← Power terminals
  │  ┌──────────────────┐   │
  │  │   L298N CHIP     │   │
  │  └──────────────────┘   │
  │  [OUT1][OUT2] [OUT3][OUT4]│  ← Motor terminals
  ├──────────────────────────┤
  │ ENA IN1 IN2 IN3 IN4 ENB│  ← Arduino control
  └──────────────────────────┘
  ■ ENA → D3(~)  Speed Motor A
  ■ IN1 → D5     Direction A
  ■ IN2 → D6     Direction A
  ■ IN3 → D7     Direction B
  ■ IN4 → D8     Direction B
  ■ ENB → D9(~)  Speed Motor B

Full Datasheet (L298N)

Motor Supply VS5V – 35V DC
Logic Supply VSS5V DC
Output Current2A per channel
Peak Current3A
PWM FrequencyUp to 40 kHz
Channels2 (Motor A & B)
Diode ProtectionBuilt-in
Speed ControlPWM via ENA/ENB

Pin Connection Table

Pin NameFunctionConnect To
IN1Motor A DirectionD5
IN2Motor A DirectionD6
ENAMotor A Speed PWMD3 (~)
IN3Motor B DirectionD7
IN4Motor B DirectionD8
ENBMotor B Speed PWMD9 (~)
12VMotor Power Input7–12V external supply
GNDCommon GroundGND (share with Arduino)
OUT1/OUT2Motor A TerminalsDC Motor A wires
OUT3/OUT4Motor B TerminalsDC Motor B wires
⚠️NEVER connect motor power to Arduino 5V pin. Always use a separate power supply (7–12V) for motors. Share GND between L298N and Arduino.

Wiring

IN1→D5 | IN2→D6 | ENA→D3(PWM) | OUT1/OUT2→Motor

Arduino Code

Arduino C++
// DC Motor L298N – LearnEmbedded
const int in1=5, in2=6, ena=3;
void setup(){ pinMode(in1,OUTPUT); pinMode(in2,OUTPUT); }
void loop(){
  digitalWrite(in1,HIGH); digitalWrite(in2,LOW);  analogWrite(ena,200); delay(2000); // Forward
  digitalWrite(in1,LOW);  digitalWrite(in2,HIGH); analogWrite(ena,200); delay(2000); // Reverse
  digitalWrite(in1,LOW);  digitalWrite(in2,LOW);  delay(1000); // Stop
}

Stepper Motor 28BYJ-48

Rotates in precise steps (512 steps = 1 full revolution). Uses ULN2003 driver module.

Specifications

Voltage5V DC
Steps/Rev512 steps
Gear Ratio64:1
DriverULN2003

Pin Diagram (ULN2003 Driver)

   ULN2003 Driver Board
  ┌────────────────────┐
  │  [Motor Connector] │  ← 5-pin JST to motor
  │  ┌──────────────┐  │
  │  │ ULN2003 IC   │  │
  │  └──────────────┘  │
  │  [●IN1][●IN2]      │  ← LEDs show step sequence
  │  [●IN3][●IN4]      │
  ├────────────────────┤
  │ IN1 IN2 IN3 IN4 │  ← Arduino pins
  │ VCC          GND │  ← Power
  └────────────────────┘
  ■ IN1 → D8   Phase 1
  ■ IN2 → D9   Phase 2
  ■ IN3 → D10  Phase 3
  ■ IN4 → D11  Phase 4
  ■ VCC → 5V   ■ GND → GND

Full Datasheet (28BYJ-48)

Voltage5V DC
Phase Resistance50 Ω / phase
Gear Ratio1:64
Step Angle5.625° / 64 = 0.088°
Steps/Rev (half)4096 steps
Steps/Rev (full)2048 steps
Max Frequency100 Hz
Torque34.3 mN·m

Pin Connection Table

Pin NameFunctionConnect To
IN1Phase 1D8
IN2Phase 2D9
IN3Phase 3D10
IN4Phase 4D11
VCCMotor Power5V
GNDGroundGND
ℹ️Use Stepper(4096, 8, 10, 9, 11) for full precision with half-stepping. setSpeed(15) gives ~15 RPM. The pin order 8,10,9,11 is important for correct coil sequence.

Wiring

IN1→D8 | IN2→D9 | IN3→D10 | IN4→D11

Arduino Code

Arduino C++
// Stepper Motor – LearnEmbedded
#include <Stepper.h>
Stepper stepper(512, 8, 10, 9, 11);
void setup(){ stepper.setSpeed(15); }
void loop(){
  stepper.step(512);  delay(500);  // Forward 1 rev
  stepper.step(-512); delay(500);  // Reverse
}

Relay Module

Electrically controlled switch. Controls high voltage AC/DC appliances with 5V Arduino signal.

Specifications

Coil Voltage5V DC
AC Rating250VAC / 10A
DC Rating30VDC / 10A
TypeActive LOW (usually)

Pin Diagram

   Relay Module (single channel)
  ┌──────────────────────┐
  │  ┌────────────────┐  │
  │  │  RELAY COIL    │  │  ← electromagnet
  │  └────────────────┘  │
  │  [LED] [Diode]       │
  ├──────────────────────┤
  │ VCC   GND   IN    │  ← Arduino side (low voltage)
  ├──────────────────────┤
  │ NO  COM  NC         │  ← AC/DC appliance side
  └──────────────────────┘
  ■ VCC → 5V       ■ GND  → GND
  ■ IN  → D7       (LOW = relay ON)
  ■ COM = Common   ■ NO   = Normally Open
  ■ NC  = Normally Closed

Full Datasheet

Coil Voltage5V DC
Coil Current70–80 mA
AC Contact10A / 250VAC
DC Contact10A / 30VDC
Min Activation V3.75V
Max Release V0.5V
Operate Time~10 ms
Release Time~5 ms

Pin Connection Table

Pin NameFunctionConnect To
VCCPower 5V5V
GNDGroundGND
INControl SignalD7 (LOW = ON)
COMCommon (appliance wire 1)AC Live / DC +
NONormally Open (appliance wire 2)AC Load terminal
NCNormally ClosedNot used (alternative)
⚠️ HIGH VOLTAGE230V AC can KILL. Never touch relay terminals when connected to mains. Always disconnect power before wiring. Use insulated connectors for AC lines.

Wiring

VCC→5V | GND→GND | IN→D7 | (LOW=ON)

Arduino Code

Arduino C++
// Relay Module – LearnEmbedded
const int relay = 7;
void setup(){ pinMode(relay,OUTPUT); digitalWrite(relay,HIGH); } // HIGH=OFF
void loop(){
  digitalWrite(relay,LOW);  delay(3000); // Device ON
  digitalWrite(relay,HIGH); delay(3000); // Device OFF
}

Buzzer (Active)

Produces sound when HIGH. Active buzzer beeps at fixed frequency. Use tone() for passive buzzer.

Specifications

Voltage5V DC
Current~30 mA
Frequency2300 Hz (active)
TypeActive / Passive

Pin Diagram

   Active Buzzer (bottom view)
      ┌───────┐
      │ ( + ) │  ← longer leg or marked +
      │       │
      │ ( - ) │  ← shorter leg or marked -
      └───────┘
       │     │
       +     -
       │     │
      D8   GND

  Active type: Sound on  → write HIGH
               Sound off → write LOW
  Passive type: Use tone(pin, freq, duration)

Full Datasheet (Active Buzzer)

Operating Voltage3.5V – 5.5V
Operating CurrentMax 35 mA
Sound Frequency2300 ± 300 Hz
Sound Pressure85 dB min @ 10 cm
Operating Temp-20°C to +60°C
Diameter12 mm

Pin Connection Table

PinPin NameFunctionConnect To
Long leg(+) PositiveSignal input / VCCD8 (any digital pin)
Short leg(−) NegativeGroundGND
ℹ️Active buzzer makes sound at fixed 2.3 kHz when HIGH. For custom tones and melodies, use a PASSIVE buzzer with tone(pin, frequency, duration) function instead.

Wiring

(+)→D8 | (-)→GND

Arduino Code

Arduino C++
// Buzzer SOS – LearnEmbedded
const int buzz = 8;
void setup(){ pinMode(buzz,OUTPUT); }
void loop(){
  for(int i=0;i<3;i++){ digitalWrite(buzz,HIGH);delay(100);digitalWrite(buzz,LOW);delay(100); }
  delay(1000);
}

Components

Essential electronic components for your microcontroller projects — sensors, motor drivers, displays and more.

🔍 Sensors

👁️

IR Sensor Module

Infrared sensor for obstacle detection and line following. Emits IR light and detects reflections from nearby objects.

Voltage3.3V – 5V
Range2 – 30 cm
OutputDigital (HIGH/LOW)
InterfaceDigital GPIO
Line Follower Obstacle Avoidance
📏

Ultrasonic Sensor HC-SR04

Measures distance using ultrasound pulses. The TRIG pin sends a pulse and ECHO pin returns the time-of-flight signal.

Voltage5V
Range2 – 400 cm
Accuracy±3 mm
Angle15°
Distance Measurement Parking Sensor
Arduino
const int trig=9, echo=10;
void setup(){pinMode(trig,OUTPUT);pinMode(echo,INPUT);}
void loop(){
  digitalWrite(trig,HIGH); delayMicroseconds(10);
  digitalWrite(trig,LOW);
  long dur=pulseIn(echo,HIGH);
  float cm=dur*0.034/2;
  Serial.println(cm);
  delay(200);
}
🌡️

DHT11 – Temperature & Humidity

Measures ambient temperature and relative humidity. Uses a single-wire digital protocol. Very popular in IoT weather station projects.

Voltage3.3V – 5V
Temp Range0 – 50°C (±2°C)
Humidity20 – 90% RH (±5%)
InterfaceSingle-wire Digital
Weather Station Smart Home

⚙️ Motor Drivers

⚙️

L298N Motor Driver

Dual H-bridge motor driver module capable of driving two DC motors bidirectionally or one stepper motor. Popular for robotics projects.

Input Voltage5V – 35V
Logic Voltage5V
Max Current2A per channel
Channels2 DC Motors
DC Motor Control Robot Car
Arduino
// Forward: IN1=H IN2=L | Reverse: IN1=L IN2=H
digitalWrite(IN1, HIGH);
digitalWrite(IN2, LOW);
analogWrite(ENA, 200); // Speed 0-255
🔌

L293D Motor Driver IC

Quad half-H driver IC for driving two DC motors or one stepper. Includes built-in protection diodes. Available as IC or shield for Arduino.

Supply Voltage4.5V – 36V
Max Current600 mA per channel
Channels2 (4 half-H)
Package16-pin DIP / SOP
Stepper Motor Small Robots
🔋

Servo Motor (SG90)

Small and lightweight servo motor with 180° rotation range. Controlled by PWM signal. Perfect for robotic arms, camera pan/tilt mounts.

Voltage4.8V – 6V
Torque1.8 kg·cm
Rotation0° – 180°
ControlPWM (50 Hz)
Robotic Arm Pan-Tilt Cam

🖥️ Displays

🖥️

LCD 16×2 (with I2C)

16 characters × 2 lines character LCD display. With an I2C module adapter, only 2 wires (SDA + SCL) are needed instead of 6–8 pins.

Voltage5V
Characters16 × 2
InterfaceParallel / I2C
I2C Address0x27 (default)
Arduino (I2C LCD)
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27,16,2);
void setup(){
  lcd.init(); lcd.backlight();
  lcd.setCursor(0,0);
  lcd.print("LearnEmbedded!");
}
📺

OLED Display 0.96" (I2C)

Compact 128×64 pixel OLED display. Very bright and power-efficient — works without backlight. Supports graphics, text, and custom bitmaps.

Voltage3.3V – 5V
Resolution128 × 64 px
InterfaceI2C / SPI
Driver ICSSD1306
Arduino (OLED)
#include <Adafruit_SSD1306.h>
Adafruit_SSD1306 oled(128,64,&Wire,-1);
void setup(){
  oled.begin(SSD1306_SWITCHCAPVCC,0x3C);
  oled.clearDisplay();
  oled.setTextSize(1);
  oled.setTextColor(WHITE);
  oled.setCursor(0,0);
  oled.println("LearnEmbedded!");
  oled.display();
}
🔢

7-Segment Display

Classic numeric display using 7 LED segments (a–g). Common cathode or common anode types. Used to display numbers 0–9 in counters and clocks.

Voltage5V (with resistors)
Digits1 per module
InterfaceDirect GPIO / 74HC595
TypesCommon Anode / Cathode
Digital Clock Counter

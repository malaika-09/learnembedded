Communication Protocols

Master UART, I2C, SPI, Bluetooth HC-05 and ESP32 WiFi for your embedded projects.

📡

UART / Serial

Simplest serial protocol. TX→RX cross-connection. Used for debugging and module communication.

Key Details

Wires2 (TX, RX)
Common Baud9600, 115200
Arduino PinsD0 (RX), D1 (TX)
LibraryBuilt-in Serial

Protocol Diagram

HC-05 Bluetooth via SoftwareSerial

Arduino PinHC-05 PinNotes
5VVCCPower
GNDGNDCommon ground
D10 (SS RX)TXDirect connection
D11 (SS TX)RXVia 1kΩ+2kΩ voltage divider (5V→3.3V)
⚠️HC-05 RX pin is 3.3V logic — use a voltage divider (1kΩ + 2kΩ) from Arduino TX. Connecting 5V directly may damage the module.

Code

Arduino C++
// UART – LearnEmbedded
void setup(){ Serial.begin(9600); Serial.println("UART Ready!"); }
void loop(){
  if(Serial.available()){
    String msg = Serial.readString();
    Serial.print("Received: "); Serial.println(msg);
  }
}

I2C Protocol

2-wire protocol (SDA + SCL). Multiple devices on same bus using unique addresses (0x27, 0x3C etc.).

Key Details

Wires2 (SDA, SCL)
Arduino PinsA4 (SDA), A5 (SCL)
DevicesUp to 127 on same bus
LibraryWire.h (built-in)

Protocol Diagram

Pin Connection Table

Device PinArduino UnoArduino MegaESP32
SDAA4D20GPIO21
SCLA5D21GPIO22
VCC3.3V or 5V3.3V or 5V3.3V
GNDGNDGNDGND
ℹ️Common I2C addresses: LCD = 0x27 or 0x3F · OLED = 0x3C · MPU6050 = 0x68 · BMP180 = 0x77. Use I2C Scanner to find unknown addresses.

I2C Scanner Code

Arduino C++
// I2C Scanner – LearnEmbedded
#include <Wire.h>
void setup(){
  Wire.begin(); Serial.begin(9600);
  for(byte a=1; a<127; a++){
    Wire.beginTransmission(a);
    if(Wire.endTransmission()==0){
      Serial.print("Found: 0x"); Serial.println(a,HEX);
    }
  }
}
void loop(){}

SPI Protocol

4-wire high-speed protocol. Master-slave architecture. Faster than I2C, used for SD cards and displays.

Key Details

Wires4 (MOSI,MISO,SCK,CS)
Arduino PinsD11,D12,D13,D10
SpeedUp to 10 Mbps
LibrarySPI.h (built-in)

Protocol Diagram

Pin Connection Table

SPI SignalArduino UnoArduino MegaESP32
MOSID11D51GPIO23
MISOD12D50GPIO19
SCKD13D52GPIO18
CS/SSD10D53GPIO5
VCC3.3V or 5V3.3V or 5V3.3V
GNDGNDGNDGND
ℹ️SPI has 4 modes (0–3) based on clock polarity and phase. Most modules use Mode 0. Check device datasheet if communication fails — try SPI.setDataMode(SPI_MODE0).

Code

Arduino C++
// SPI – LearnEmbedded
#include <SPI.h>
const int CS = 10;
void setup(){ SPI.begin(); pinMode(CS,OUTPUT); digitalWrite(CS,HIGH); }
void sendByte(byte data){
  digitalWrite(CS,LOW);
  SPI.transfer(data);
  digitalWrite(CS,HIGH);
}
void loop(){ sendByte(0xAB); delay(1000); }

Bluetooth HC-05

Classic Bluetooth module for wireless serial communication up to 10m. Pair with Android app easily.

Key Details

Voltage3.3V – 6V
RangeUp to 10 meters
Default PIN1234
Baud Rate9600 (default)

RangeUp to 10 m

AT Mode Baud38400 bps
Supply Voltage3.3V – 6V
TX/RX Voltage3.3V logic
Default PIN1234 or 0000

Pin Connection Table

HC-05 PinFunctionArduino ConnectionNotes
VCCPower5V
GNDGroundGND
TXTransmitD10 (SS RX)Direct — 3.3V safe
RXReceiveD11 via divider5V→3.3V divider needed!
STATEStatus LEDOptional D4HIGH when connected
EN/KEYAT ModeOptional D5HIGH for AT commands
⚠️HC-05 RX operates at 3.3V. Connecting Arduino 5V TX directly will damage the module over time. Use a 1kΩ + 2kΩ resistor voltage divider on the TX→RX line.

Wiring

VCC→5V | GND→GND | TX→D10 | RX→D11(via divider)

Code

Arduino C++
// Bluetooth HC-05 – LearnEmbedded
#include <SoftwareSerial.h>
SoftwareSerial bt(10,11);
void setup(){ Serial.begin(9600); bt.begin(9600); }
void loop(){
  if(bt.available()){
    char c = bt.read();
    if(c=='1'){ digitalWrite(13,HIGH); bt.println("LED ON"); }
    if(c=='0'){ digitalWrite(13,LOW);  bt.println("LED OFF"); }
  }
}

Connect to WiFi + Web Server

Arduino C++ (ESP32)
// ESP32 WiFi Web Server – LearnEmbedded
#include <WiFi.h>
#include <WebServer.h>
const char* ssid = "Your_WiFi";
const char* pass = "Your_Password";
WebServer server(80);
void handleRoot(){ server.send(200,"text/html","<h1>Hello from ESP32!</h1>"); }
void setup(){
  Serial.begin(115200);
  WiFi.begin(ssid,pass);
  while(WiFi.status()!=WL_CONNECTED) delay(500);
  Serial.println(WiFi.localIP());
  server.on("/",handleRoot); server.begin();
}
void loop(){ server.handleClient(); }

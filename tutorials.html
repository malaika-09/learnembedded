Beginner Arduino

Getting Started with Arduino

Install the IDE, understand the board layout, and write your first Arduino sketch from scratch.

What You Will Learn

  • How to install and setup Arduino IDE
  • Understanding the Arduino Uno board layout
  • Writing and uploading your first sketch
  • Using digitalWrite(), analogRead(), and Serial.print()

Step 1 – Install Arduino IDE

1

Download Arduino IDE

Visit arduino.cc/en/software and download the IDE for your operating system (Windows / Mac / Linux).

2

Install the IDE

Run the installer and follow the prompts. Accept the driver installation when asked — this is needed for USB communication with the board.

3

Connect Arduino to PC

Plug the Arduino Uno into your PC using a USB Type-B cable. Windows will automatically install drivers.

4

Select Board & Port

In the IDE: Tools → Board → Arduino Uno, then Tools → Port → COM3 (or whichever port appears).

Tip: If no port appears, try a different USB cable — many cables are charge-only and don't carry data.

Step 2 – Your First Sketch (Blink)

Every Arduino sketch has two main functions: setup() which runs once at startup, and loop() which runs repeatedly forever.

Arduino C++ 
// Your First Arduino Sketch
// This is the setup() function – runs ONCE at startup
void setup() {
  pinMode(13, OUTPUT);    // Set pin 13 as output
  Serial.begin(9600);     // Start serial at 9600 baud
  Serial.println("Arduino Ready!");
}

// This is the loop() function – runs FOREVER
void loop() {
  digitalWrite(13, HIGH);    // LED ON
  Serial.println("LED is ON");
  delay(1000);

  digitalWrite(13, LOW);     // LED OFF
  Serial.println("LED is OFF");
  delay(1000);
}

Step 3 – Upload the Sketch

Click the → Upload button (right arrow) in the IDE. The IDE will compile the code and upload it to the Arduino. You will see the TX/RX LEDs flash rapidly during upload. After "Done uploading" appears, the LED will start blinking.

Note: Open Serial Monitor (Ctrl+Shift+M) and set baud rate to 9600 to see the "LED is ON/OFF" messages printed in real time.

Arduino Digital I/O, Analog & PWM

Read sensors, control LEDs with PWM, and use analogRead() to measure voltages.

Analog Read – Potentiometer

Connect a potentiometer's middle pin to A0, one end to 5V, and other to GND. Then read its value:

Arduino C++
void setup() { Serial.begin(9600); }

void loop() {
  int raw = analogRead(A0);         // 0 – 1023
  float voltage = raw * (5.0 / 1023.0); // Convert to volts
  Serial.print("Raw: "); Serial.print(raw);
  Serial.print("  Voltage: "); Serial.println(voltage);
  delay(200);
}

PWM – LED Fade Effect

PWM pins (marked with ~) can output variable brightness. Use analogWrite(pin, 0–255) to control LED brightness:

Arduino C++
const int ledPin = 9;  // Must be a PWM pin (~)

void setup() { pinMode(ledPin, OUTPUT); }

void loop() {
  // Fade in
  for (int i = 0; i <= 255; i++) {
    analogWrite(ledPin, i);
    delay(8);
  }
  // Fade out
  for (int i = 255; i >= 0; i--) {
    analogWrite(ledPin, i);
    delay(8);
  }
}
Tip: Arduino PWM pins are 3, 5, 6, 9, 10, 11. Only these support analogWrite().

ESP32 WiFi Basics

Connect ESP32 to your WiFi network, get its IP address, and create a simple web server.

Prerequisites

  • Arduino IDE installed (v2.x recommended)
  • ESP32 board package installed via Boards Manager
  • ESP32 DevKit board and USB cable

Step 1 – Add ESP32 to Arduino IDE

1

Add Board Manager URL

Go to File → Preferences and paste this URL in "Additional Boards Manager URLs":

URL
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
2

Install ESP32 Package

Go to Tools → Board → Boards Manager, search "esp32" and install the package by Espressif Systems.

3

Select Board

Go to Tools → Board → ESP32 Arduino → ESP32 Dev Module.

Step 2 – Connect to WiFi

Arduino C++ (ESP32)
#include <WiFi.h>

const char* ssid     = "Your_WiFi_Name";
const char* password = "Your_WiFi_Password";

void setup() {
  Serial.begin(115200);
  Serial.print("Connecting to WiFi");

  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("\nConnected! IP: ");
  Serial.println(WiFi.localIP());
}

void loop() {}

Step 3 – Create a Simple Web Server

Arduino C++ (ESP32)
#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "Your_WiFi";
const char* pass = "Your_Password";

WebServer server(80);

void handleRoot() {
  server.send(200, "text/html",
    "<h1 style='font-family:sans-serif;color:#2563eb'>"
    "Hello from ESP32! 📡</h1>");
}

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, pass);
  while(WiFi.status() != WL_CONNECTED) delay(500);
  Serial.println(WiFi.localIP());

  server.on("/", handleRoot);
  server.begin();
}

void loop() { server.handleClient(); }
Output: Open Serial Monitor at 115200 baud. Copy the IP address shown and open it in your browser on the same WiFi network. You will see the "Hello from ESP32!" page.

Bonus – ESP32 BLE (Bluetooth Low Energy) Scanner

Arduino C++ (ESP32)
#include <BLEDevice.h>
#include <BLEScan.h>

BLEScan* pBLEScan;

void setup() {
  Serial.begin(115200);
  BLEDevice::init("");
  pBLEScan = BLEDevice::getScan();
  pBLEScan->setActiveScan(true);

  BLEScanResults results = pBLEScan->start(5); // Scan 5 seconds
  Serial.print("Devices found: ");
  Serial.println(results.getCount());
}

void loop() {}

PIC Programming Basics

Setup MPLAB X IDE, write your first C program for PIC16F877A, and control GPIO pins.

Step 1 – Install Tools

1

Download MPLAB X IDE

Go to microchip.com and download MPLAB X IDE (free). Install it with all default options.

2

Install XC8 Compiler

Also from Microchip's site, download the XC8 Compiler (free version). This compiles C code for 8-bit PIC chips.

3

Create New Project

Open MPLAB X → File → New Project → Standalone Project → select PIC16F877A → select XC8 compiler.

Note: You need a PIC programmer like PICkit 3/4 or a compatible clone to upload code to the PIC chip.

Step 2 – LED Blink in C (PIC16F877A)

C (XC8 / MPLAB)
// PIC16F877A LED Blink – LearnEmbedded
// LED connected to RB0 (Pin 33)

#include <xc.h>

// Configuration bits
#pragma config FOSC = HS       // High-speed oscillator
#pragma config WDTE = OFF      // Watchdog timer OFF
#pragma config PWRTE = OFF
#pragma config BOREN = ON
#pragma config LVP = OFF

#define _XTAL_FREQ 8000000   // 8 MHz crystal
#define LED        RB0

void main(void) {
  TRISB0 = 0;   // RB0 as output (0=output, 1=input)

  while(1) {
    LED = 1;            // LED ON
    __delay_ms(500);
    LED = 0;            // LED OFF
    __delay_ms(500);
  }
}

Step 3 – Read a Button with PIC

C (XC8)
#include <xc.h>
#define _XTAL_FREQ 8000000

void main() {
  TRISB0 = 0;  // RB0 = LED output
  TRISB1 = 1;  // RB1 = Button input

  while(1) {
    if(RB1 == 1) {  // Button pressed
      RB0 = 1;       // LED ON
    } else {
      RB0 = 0;       // LED OFF
    }
  }
}
Tip: In MPLAB X, use the simulator (Debug → Simulate) to test your code without physical hardware. Toggle pins in the Stimulus window.

Arduino Uno

The most popular open-source microcontroller board for beginners and prototyping

Overview

The Arduino Uno is based on the ATmega328P microcontroller and operates at 5V with a 16 MHz crystal oscillator. It has 14 digital I/O pins, 6 analog inputs, a USB connection, a power jack, and a reset button. It is the most used board for beginners due to its simple programming interface via the Arduino IDE using C/C++ language.

Key Features

ATmega328P @ 16 MHz
32 KB Flash, 2 KB SRAM
14 Digital I/O Pins
6 PWM Outputs
6 Analog Inputs (10-bit ADC)
5V / 3.3V Operating Voltage
USB Type-B for Programming
UART, SPI, I2C Support

Pin Diagram

Applications

LED Control
Sensor Reading
Simple Robots
Music Players
Security Systems
RC Cars

Pros & Cons

✅ Pros
  • Beginner friendly with huge community
  • Free Arduino IDE with simple syntax
  • Thousands of free libraries
  • Cheap and widely available
  • USB plug-and-play programming
❌ Cons
  • Limited processing speed (16 MHz)
  • Only 2 KB SRAM – very limited RAM
  • No built-in WiFi or Bluetooth
  • 5V logic – not 3.3V compatible by default
  • Limited for complex real-time tasks

ESP32

Low-cost, low-power microcontroller with integrated WiFi and Bluetooth for IoT projects

Overview

The ESP32 by Espressif Systems is a dual-core 32-bit microcontroller with built-in 2.4 GHz WiFi and Bluetooth 4.2/BLE. Operating at up to 240 MHz, it is ideal for IoT applications. It supports Arduino IDE, MicroPython, and ESP-IDF frameworks and features a rich set of peripherals including capacitive touch sensors, Hall effect sensor, SD card interface, Ethernet, high-speed SPI, UART, I2S, and I2C.

Key Features

Xtensa LX6 Dual-Core @ 240 MHz
520 KB SRAM, up to 16 MB Flash
Built-in 2.4 GHz WiFi (802.11 b/g/n)
Bluetooth 4.2 Classic + BLE
36 GPIO Pins
18-ch 12-bit ADC, 2 DAC
Capacitive Touch Sensing
Ultra-low Power Deep Sleep

Pin Diagram

Applications

Smart Home IoT
Cloud Data Logging
WiFi Web Server
BLE Game Controller
ESP32-CAM Projects
Weather Stations

Pros & Cons

✅ Pros
  • Built-in WiFi and Bluetooth — no extra modules
  • Powerful dual-core 240 MHz processor
  • Supports Arduino IDE and MicroPython
  • Very affordable (~$3–5)
  • Rich set of peripherals
❌ Cons
  • 3.3V logic — not directly 5V compatible
  • Higher power consumption than ATmega
  • Some ADC pins are restricted when WiFi is active
  • Boot issues on GPIO 0, 2, 15
  • More complex than Arduino for absolute beginners

PIC Microcontroller

Industry-standard microcontrollers by Microchip Technology – widely used in professional embedded systems

Overview

PIC (Peripheral Interface Controller) microcontrollers by Microchip Technology are a family of 8/16/32-bit controllers used extensively in industry. The PIC16F877A is the most commonly used in academics. They are programmed using MPLAB X IDE with XC8/XC16 compiler in C language. PIC controllers are known for their reliability, rich peripherals, and low power consumption.

Key Features (PIC16F877A)

8-bit RISC Architecture @ 20 MHz
14 KB Flash, 368 Bytes RAM
33 I/O Pins (5 Ports: A–E)
8-ch 10-bit ADC
3 Timers (Timer0, Timer1, Timer2)
2 CCP (PWM/Capture/Compare)
USART, SPI, I2C
2.0V – 5.5V Operating Voltage

Pin Diagram

Applications

Industrial Control
Automotive Systems
Medical Devices
Motor Control
Communication Devices
Energy Meters

Pros & Cons

✅ Pros
  • Industry standard — widely used professionally
  • Excellent documentation and application notes
  • Low power and high reliability
  • Wide voltage range (2V–5.5V)
  • Many variants for specific applications
❌ Cons
  • Steeper learning curve than Arduino
  • Requires MPLAB IDE + programmer hardware
  • Less community support for beginners
  • Assembly or C required — no simplified IDE
  • Slower prototyping than Arduino

Raspberry Pi 4

Powerful Linux-based single-board computer for advanced projects, media, and learning

Overview

The Raspberry Pi is a credit-card sized single-board computer developed by the Raspberry Pi Foundation. Unlike typical microcontrollers, it runs a full Linux operating system (Raspberry Pi OS). It features HDMI output, USB ports, camera interface, and 40 GPIO pins. It can run Python, C, Java, and many other languages, making it suitable for complex applications like AI, computer vision, and servers.

Key Features (Pi 4 Model B)

ARM Cortex-A72 Quad-Core @ 1.8 GHz
2 / 4 / 8 GB LPDDR4 RAM
Dual-band 2.4/5 GHz WiFi
Bluetooth 5.0 + BLE
40 GPIO Pins
Dual Micro-HDMI (4K support)
2× USB 3.0 + 2× USB 2.0
Gigabit Ethernet

GPIO Pin Layout

Applications

AI / Machine Learning
Computer Vision
Home Server / NAS
Retro Gaming (RetroPie)
Robotics (ROS)
Desktop Computer

Pros & Cons

✅ Pros
  • Full Linux OS — runs any software
  • Very powerful (Quad-core + GBs of RAM)
  • Huge community and documentation
  • HDMI, USB, Ethernet, WiFi built-in
  • Supports Python, Node.js, Java, etc.
❌ Cons
  • More expensive (~$35–$75)
  • No built-in ADC (analog reading)
  • Needs OS installation on microSD
  • Slower boot than bare microcontrollers
  • Higher power — not suitable for battery IoT

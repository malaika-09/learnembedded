LED Blinking with Arduino

The classic first project for every microcontroller beginner. Control an LED's on/off state using Arduino's digital output pin and learn the basic structure of an Arduino program.

Beginner Arduino Digital I/O

Components Required

Arduino Uno × 1
LED (any colour) × 1
Resistor 220Ω × 1
Breadboard × 1
Jumper Wires
USB Cable × 1

Circuit Diagram

💡 Arduino Pin 13 → 220Ω Resistor → LED Anode → LED Cathode → GND [ Connect longer leg (+) of LED to resistor, shorter leg (-) to GND ]

Arduino Code

Arduino C++ 
// LED Blinking – LearnEmbedded
// Blink an LED connected to digital pin 13

const int ledPin = 13;   // Built-in LED pin

void setup() {
  pinMode(ledPin, OUTPUT);   // Set pin as output
}

void loop() {
  digitalWrite(ledPin, HIGH);  // LED ON
  delay(1000);                  // Wait 1 second
  digitalWrite(ledPin, LOW);   // LED OFF
  delay(1000);                  // Wait 1 second
}

Expected Output

The LED connected to pin 13 will turn ON for 1 second, then OFF for 1 second, repeating continuously. You can change the delay values to control the blink speed. Try delay(100) for a fast blink!

Line Follower Robot

Build an autonomous robot that follows a black line on a white surface using IR sensors and an Arduino. This project teaches sensor interfacing, motor control, and basic robotics logic.

Intermediate Arduino IR Sensor · L298N

Components Required

Arduino Uno × 1
IR Sensor Module × 2
L298N Motor Driver × 1
DC Motors × 2
Wheels × 2 + Caster × 1
Chassis Board × 1
9V Battery × 1
Jumper Wires

Circuit Diagram

🤖 IR Left → D2 | IR Right → D3 | L298N IN1→D5 IN2→D6 IN3→D9 IN4→D10 [ L298N 12V from battery · 5V from Arduino · GND common ]

Arduino Code

Arduino C++ 
// Line Follower Robot – LearnEmbedded
// Uses 2 IR sensors and L298N motor driver

// IR Sensor pins
const int irLeft  = 2;
const int irRight = 3;

// Motor driver pins (Left Motor)
const int in1 = 5, in2 = 6;
// Motor driver pins (Right Motor)
const int in3 = 9, in4 = 10;

void setup() {
  pinMode(irLeft,  INPUT);
  pinMode(irRight, INPUT);
  pinMode(in1, OUTPUT); pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT); pinMode(in4, OUTPUT);
}

void forward()  { digitalWrite(in1,HIGH); digitalWrite(in2,LOW);  digitalWrite(in3,HIGH); digitalWrite(in4,LOW); }
void turnLeft() { digitalWrite(in1,LOW);  digitalWrite(in2,HIGH); digitalWrite(in3,HIGH); digitalWrite(in4,LOW); }
void turnRight(){ digitalWrite(in1,HIGH); digitalWrite(in2,LOW);  digitalWrite(in3,LOW);  digitalWrite(in4,HIGH); }
void stopMotors(){ digitalWrite(in1,LOW);  digitalWrite(in2,LOW);  digitalWrite(in3,LOW);  digitalWrite(in4,LOW); }

void loop() {
  int L = digitalRead(irLeft);   // 0 = black line detected
  int R = digitalRead(irRight);

  if      (!L && !R) forward();    // Both on line → go forward
  else if (!L &&  R) turnLeft();   // Only left on line → turn left
  else if ( L && !R) turnRight(); // Only right on line → turn right
  else               stopMotors(); // Off line → stop
}

Expected Output

The robot will follow a black tape line on a white surface. When both IR sensors detect the line, it moves forward. When only one sensor detects the line, it corrects its direction accordingly. Place the robot on a track and watch it navigate autonomously!

Bluetooth Controlled Car

Build a wireless RC car controlled from your Android smartphone via Bluetooth. Uses the HC-05 module with Arduino and the L298N motor driver for full directional control.

Intermediate Arduino HC-05 · Bluetooth

Components Required

Arduino Uno × 1
HC-05 BT Module × 1
L298N Motor Driver × 1
DC Motors × 4
Car Chassis × 1
12V Battery Pack × 1
Android Phone
Jumper Wires

Circuit Diagram

📱 HC-05 TX→D10 RX→D11(via divider) VCC→5V GND→GND [ Use voltage divider on HC-05 RX: 1kΩ + 2kΩ to convert 5V→3.3V ]

Arduino Code

Arduino C++ 
// Bluetooth Controlled Car – LearnEmbedded
// Commands: F=Forward, B=Back, L=Left, R=Right, S=Stop

#include <SoftwareSerial.h>

SoftwareSerial bt(10, 11);  // RX, TX for HC-05

const int in1=5, in2=6, in3=9, in4=10;
const int ena=3, enb=11;  // PWM speed pins

void setup() {
  bt.begin(9600);
  int pins[] = {in1,in2,in3,in4,ena,enb};
  for(int p : pins) pinMode(p, OUTPUT);
  analogWrite(ena, 200);  // Set speed (0–255)
  analogWrite(enb, 200);
}

void loop() {
  if (bt.available()) {
    char cmd = (char)bt.read();
    switch(cmd) {
      case 'F': move(HIGH,LOW,HIGH,LOW); break;
      case 'B': move(LOW,HIGH,LOW,HIGH); break;
      case 'L': move(LOW,HIGH,HIGH,LOW); break;
      case 'R': move(HIGH,LOW,LOW,HIGH); break;
      default:  move(LOW,LOW,LOW,LOW);   // Stop
    }
  }
}

void move(int a, int b, int c, int d) {
  digitalWrite(in1,a); digitalWrite(in2,b);
  digitalWrite(in3,c); digitalWrite(in4,d);
}

Expected Output

Pair your phone with HC-05 (default PIN: 1234). Use any Bluetooth terminal app (e.g., "Arduino Bluetooth Controller") to send characters. Send F to go forward, B backward, L left, R right, S stop.

Smart Home Automation (ESP32)

Control home appliances like lights and fans from anywhere using a web browser. ESP32 hosts a WiFi web server accessible on your local network. Toggle relays from a mobile-friendly dashboard.

Advanced ESP32 WiFi · Web Server · IoT

Components Required

ESP32 DevKit × 1
4-Ch Relay Module × 1
Bulb / Fan × 1–4
DHT11 Sensor × 1
Power Supply 5V/2A
Jumper Wires

Circuit Diagram

🏠 Relay IN1→GPIO26 IN2→GPIO27 IN3→GPIO14 IN4→GPIO12 | DHT11→GPIO4 [ Relay VCC→5V · GND→GND · ESP32 GPIO are 3.3V, use optocoupler relay module ]

ESP32 Code (Arduino IDE)

Arduino C++ (ESP32) 
// Smart Home Automation – LearnEmbedded
#include <WiFi.h>
#include <WebServer.h>

const char* ssid     = "Your_WiFi_SSID";
const char* password = "Your_WiFi_Password";

WebServer server(80);

const int relay[] = {26, 27, 14, 12};
bool state[] = {false, false, false, false};

const char* labels[] = {"Light", "Fan", "AC", "TV"};

void handleRoot() {
  String html = "<!DOCTYPE html><html><head>";
  html += "<meta name='viewport' content='width=device-width'>";
  html += "<style>body{font-family:sans-serif;text-align:center;background:#0f172a;color:white}";
  html += "button{padding:12px 28px;margin:8px;border-radius:8px;border:none;cursor:pointer;font-size:1rem}";
  html += ".on{background:#10b981}.off{background:#ef4444}</style></head><body>";
  html += "<h1>🏠 Smart Home Control</h1>";

  for(int i = 0; i < 4; i++) {
    html += "<p>" + String(labels[i]) + ": <a href='/toggle?pin=" + i + "'>";
    html += "<button class='" + String(state[i] ? "on" : "off") + "'>";
    html += state[i] ? "ON" : "OFF";
    html += "</button></a></p>";
  }
  html += "</body></html>";
  server.send(200, "text/html", html);
}

void handleToggle() {
  int pin = server.arg("pin").toInt();
  if(pin >= 0 && pin < 4) {
    state[pin] = !state[pin];
    digitalWrite(relay[pin], state[pin] ? HIGH : LOW);
  }
  server.sendHeader("Location", "/");
  server.send(302);
}

void setup() {
  Serial.begin(115200);
  for(int i=0; i<4; i++) { pinMode(relay[i],OUTPUT); digitalWrite(relay[i],LOW); }
  WiFi.begin(ssid, password);
  while(WiFi.status() != WL_CONNECTED) { delay(500); }
  Serial.println(WiFi.localIP());
  server.on("/", handleRoot);
  server.on("/toggle", handleToggle);
  server.begin();
}

void loop() { server.handleClient(); }

Expected Output

After uploading, open the Serial Monitor at 115200 baud to see the ESP32's IP address. Open that IP in any browser on the same WiFi network. You will see a web dashboard with toggle buttons for each appliance. Click to turn them ON/OFF and the relay will switch accordingly.

Smart Temperature Monitor (DHT11 + LCD)

Display real-time temperature and humidity on LCD 16x2 using DHT11 sensor. Get serial alerts when temperature exceeds threshold.

Intermediate Arduino DHT11 · LCD · I2C

Components Required

Arduino Uno
DHT11 Sensor
LCD 16x2
I2C Module
Buzzer
Jumper Wires

Circuit Diagram

🌡️ DHT11 DATA → D2 | LCD I2C SDA → A4 SCL → A5 | Buzzer → D8 [ DHT11: VCC→5V, GND→GND, DATA→D2 with 10kΩ pull-up ]

Arduino Code

Arduino C++ 
// Temperature Monitor – LearnEmbedded
#include <DHT.h>
#include <LiquidCrystal_I2C.h>

#define DHTPIN 2
#define DHTTYPE DHT11
#define BUZZER 8
#define TEMP_LIMIT 35

DHT dht(DHTPIN, DHTTYPE);
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  dht.begin();
  lcd.init(); lcd.backlight();
  pinMode(BUZZER, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  float temp = dht.readTemperature();
  float hum  = dht.readHumidity();
  lcd.clear();
  lcd.setCursor(0,0); lcd.print("Temp: "); lcd.print(temp); lcd.print("C");
  lcd.setCursor(0,1); lcd.print("Hum:  "); lcd.print(hum);  lcd.print("%");
  if (temp > TEMP_LIMIT) {
    digitalWrite(BUZZER, HIGH);
    Serial.println("WARNING: High Temperature!");
  } else {
    digitalWrite(BUZZER, LOW);
  }
  delay(2000);
}

Expected Output

LCD shows live temperature and humidity readings. When temperature exceeds 35°C, the buzzer sounds and a warning message is printed to Serial Monitor.

LED Chaser (Shift Register)

Create a running LED chaser pattern using 8 LEDs and 74HC595 shift register. Control 8 LEDs with only 3 Arduino pins.

Beginner Arduino 74HC595 · Shift Register

Components Required

Arduino Uno
74HC595 Shift Register
8x LEDs
8x 220Ω Resistors
Breadboard
Jumper Wires

Circuit Diagram

✨ 74HC595: DS(14)→D2 | SH_CP(11)→D3 | ST_CP(12)→D4 | Q0–Q7→LEDs via 220Ω [ VCC→5V, GND→GND, OE(13)→GND, MR(10)→5V ]

Arduino Code

Arduino C++ 
// LED Chaser – LearnEmbedded
const int dataPin  = 2;
const int clockPin = 3;
const int latchPin = 4;

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

void shiftOut595(byte data) {
  digitalWrite(latchPin, LOW);
  shiftOut(dataPin, clockPin, MSBFIRST, data);
  digitalWrite(latchPin, HIGH);
}

void loop() {
  // Chase forward
  for (int i = 0; i < 8; i++) {
    shiftOut595(1 << i);
    delay(100);
  }
  // Chase backward
  for (int i = 7; i >= 0; i--) {
    shiftOut595(1 << i);
    delay(100);
  }
}

Expected Output

8 LEDs will light up one at a time in a chasing pattern — first forward (LED 1 to 8), then backward (LED 8 to 1), repeating continuously at 100ms intervals.

Ultrasonic Distance Meter (OLED)

Measure distance with HC-SR04 ultrasonic sensor and display on OLED screen with a real-time bar graph. Buzzer beeps faster as object gets closer.

Intermediate Arduino HC-SR04 · OLED · SSD1306

Components Required

Arduino Uno
HC-SR04 Sensor
OLED 0.96" I2C
Buzzer
Jumper Wires

Circuit Diagram

📏 TRIG→D9 | ECHO→D10 | BUZZ→D6 | OLED SDA→A4 SCL→A5 [ HC-SR04 VCC→5V, GND→GND | OLED VCC→3.3V or 5V ]

Arduino Code

Arduino C++ 
// Ultrasonic Distance Meter – LearnEmbedded
#include <Adafruit_SSD1306.h>
Adafruit_SSD1306 oled(128, 64, &Wire, -1);

const int TRIG = 9, ECHO = 10, BUZZ = 6;

long getDistance() {
  digitalWrite(TRIG, HIGH); delayMicroseconds(10); digitalWrite(TRIG, LOW);
  return pulseIn(ECHO, HIGH) * 0.034 / 2;
}

void setup() {
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT); pinMode(BUZZ, OUTPUT);
  oled.begin(SSD1306_SWITCHCAPVCC, 0x3C);
}

void loop() {
  long dist = getDistance();
  oled.clearDisplay();
  oled.setTextSize(2); oled.setTextColor(WHITE);
  oled.setCursor(0, 0); oled.print(dist); oled.print(" cm");
  // Bar graph
  int barW = map(constrain(dist, 0, 100), 0, 100, 128, 0);
  oled.fillRect(0, 40, barW, 16, WHITE);
  oled.display();
  // Proximity beep
  if (dist < 20) { tone(BUZZ, 1000, 50); delay(map(dist,0,20,50,300)); }
  else delay(200);
}

Expected Output

OLED displays live distance in cm with a shrinking bar graph. When object is within 20cm, the buzzer beeps — faster as it gets closer.

Password Door Lock (Keypad + Servo)

Build a 4-digit password door lock using a 4x4 keypad and servo motor. Wrong password triggers a buzzer alarm. Password can be changed via keypad.

Advanced Arduino Keypad · Servo · LCD

Components Required

Arduino Uno
4x4 Keypad
Servo Motor SG90
LCD 16x2 I2C
Buzzer
Jumper Wires

Circuit Diagram

🔐 Keypad rows→D9,D8,D7,D6 cols→D5,D4,D3,D2 | Servo→D10 | Buzzer→A0 | LCD I2C→A4/A5 [ Servo VCC→5V | LCD VCC→5V | All GND→GND ]

Arduino Code

Arduino C++ 
// Password Door Lock – LearnEmbedded
#include <Keypad.h>
#include <Servo.h>
#include <LiquidCrystal_I2C.h>

const String PASSWORD = "1234";
String input = "";
Servo servo;
LiquidCrystal_I2C lcd(0x27, 16, 2);

const byte ROWS = 4, COLS = 4;
char keys[ROWS][COLS] = {
  {'1','2','3','A'},{'4','5','6','B'},
  {'7','8','9','C'},{'*','0','#','D'}
};
byte rowPins[4]={9,8,7,6}, colPins[4]={5,4,3,2};
Keypad keypad = Keypad(makeKeymap(keys),rowPins,colPins,ROWS,COLS);

void setup() {
  servo.attach(10); servo.write(0);
  lcd.init(); lcd.backlight();
  lcd.print("Enter Password:");
}

void loop() {
  char key = keypad.getKey();
  if (!key) return;
  if (key == '#') {
    if (input == PASSWORD) {
      lcd.clear(); lcd.print("Access Granted!");
      servo.write(90); delay(3000); servo.write(0);
    } else {
      lcd.clear(); lcd.print("Wrong Password!");
      tone(A0, 500, 1000);
    }
    input = ""; delay(1500);
    lcd.clear(); lcd.print("Enter Password:");
  } else if (key == '*') {
    input = ""; lcd.clear(); lcd.print("Enter Password:");
  } else {
    input += key;
    lcd.setCursor(input.length()-1, 1); lcd.print('*');
  }
}

Expected Output

LCD prompts for password entry. Correct password (1234) rotates servo to 90° for 3 seconds then resets. Wrong password sounds buzzer alarm. Press * to clear and retry.
